# Demo image attribution

`sample_daisy.jpg` is an unchanged copy of Flower Photos training image `daisy/10140303196_b88d3d6cec.jpg`.

**Photographer:** Irene Grassi. **Source:** https://www.flickr.com/photos/sun_sand_sea/10140303196/ . The dataset credits identify the image as CC-BY. The full original licensing/attribution record is retained in `../docs/DATASET_IMAGE_CREDITS.txt`.

This image is included for a functional inference/demo check. It does not supply evidence of performance on unseen images. Grad-CAM panels elsewhere are annotated derivatives of the credited source photographs; each panel and the review log identify its source filename. Image licenses remain separate from the code license.
